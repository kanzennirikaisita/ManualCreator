# Manual Clip - 手順メモ Edge拡張機能

Edgeで開いているWebページの操作を記録し、クリック位置つきキャプチャとメモを蓄積して、手順書素材を作成するローカル完結型の拡張機能です。

## 主な機能

- サイドバーで記録開始・停止
- ページ内クリックごとに画面キャプチャを自動追加
- クリック位置を小さな赤丸で強調
- 最新の手順を一覧の上側へ追加
- 各手順の説明文・補足を編集
- 手順の並び替え、削除
- 画像編集：モザイク、赤枠、矢印、切り抜き、Undo
- Word向けコピー、HTML保存
- Excel向け表コピー、Excel表保存
- Markdownコピー、Markdown保存
- 標準・コンパクト・詳細の出力テンプレート
- JSON保存・読込

## Edgeへの追加方法

1. Edgeで `edge://extensions/` を開く
2. 左下の **開発者モード** をオンにする
3. **展開して読み込み** をクリック
4. このフォルダーを選択
5. ツールバーの拡張機能アイコンから **Manual Clip** を開く

## 画像編集

各手順の **画像を編集** を押すと、専用画面が開きます。赤枠、矢印、モザイク、切り抜き範囲を選び、画像上をドラッグしてください。切り抜きは範囲指定後に **切り抜きを適用** を押します。最後に **保存して閉じる** を押すと手順へ反映されます。

## Excel出力

- **Excel向けコピー**：文章情報をタブ区切り形式でコピーします。ExcelのA1セルへ貼り付けてください。
- **Excel表保存**：画像を含む表を `.xls` 形式で保存します。Excelで開いて調整できます。

## 注意

- キャプチャ画像は `chrome.storage.local` に保存され、外部送信しません。
- `chrome://`、Edge設定画面、拡張機能ストアなど、ブラウザが拡張機能の実行を禁止しているページでは記録できません。
- Markdown出力では画像をデータURLで埋め込むため、ファイルサイズが大きくなります。
- 画像を編集して保存すると、クリック位置の赤丸は画像へ焼き付けられます。
