# Manual Clip - 手順メモ Edge拡張機能

Edgeで開いているWebページの操作を記録し、クリック位置つきキャプチャとメモを蓄積して、手順書素材を作成するローカル完結型の拡張機能です。

## できること

- サイドバーで記録開始・停止
- ページ内クリックごとに画面キャプチャを自動追加
- クリック位置を小さな赤丸で強調
- 最新の手順を一覧の上側へ追加
- 各手順の説明文・補足を編集
- 手順の並び替え、削除
- Word向けに画像込みHTMLをクリップボードへコピー
- HTMLファイル保存
- JSON保存・読込

## Edgeへの追加方法

1. Edgeで `edge://extensions/` を開く
2. 左下の **開発者モード** をオンにする
3. **展開して読み込み** をクリック
4. この `manual-clip-edge` フォルダーを選択
5. ツールバーの拡張機能アイコンから **Manual Clip** を開く

## 使い方

1. サイドバーで手順書タイトルを入力
2. **記録開始** を押す
3. 対象のWebページを通常どおり操作する
4. クリックごとにキャプチャが追加される
5. **記録停止** を押す
6. 不要な手順を削除し、説明文を修正
7. **Word向けコピー** を押して Word に貼り付ける

## 注意

- キャプチャ画像は `chrome.storage.local` に保存され、外部送信しません。
- 公開したくない情報が写り込んだ画像は、出力前に削除してください。
- `chrome://`、Edge設定画面、拡張機能ストアなど、ブラウザが拡張機能の実行を禁止しているページでは記録できません。
- Excelへ画像込みで一括貼り付ける用途は未対応です。まずはWord向けの手順書作成を主目的にしています。
- 画面遷移後に撮るため、クリックから約0.45秒後にキャプチャします。重い画面では遷移途中が撮れる場合があります。
